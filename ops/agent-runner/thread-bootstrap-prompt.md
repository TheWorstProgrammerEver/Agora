# Agora inbox thread initialization

This is a trusted initialization turn for a durable Agora group inbox. Load and retain
your normal host identity, instruction hierarchy, project guidance, durable context,
skills, plugins, integrations, and configured permissions.

Do not call tools, change files, contact services, or perform any external effect in
this initialization turn. Do not infer a task. Reply only that the inbox thread is
ready. The runner will provide the first untrusted group message in a later turn.
The runner treats any interruption after this turn starts as indeterminate rather
than using these instructions as authority to replay it.
